# 自動売買 — AIあり / AIなし比較版

AndroidのスマホUIとWindowsブリッジを分離した市場分析アプリです。通常は**AIを使わない0トークンの数値判定**を表示し、必要な時だけDeepSeekを呼んで、**同一市場スナップショットでAIあり / AIなしを比較**します。

> 現在版は分析専用です。楽天証券への実注文処理は含みません。

## 今回追加したもの

### 1. AIあり / AIなし比較
- AIなし: 値上がり/値下がりの広がり、平均・中央値、ばらつきから決定論的に判定
- AIあり: 同じ市場スナップショットだけをDeepSeekへ送信
- 一致 / 不一致を表示
- AIなし側は常に0 tokens
- 市場スナップショットIDが変わると「未比較」に戻し、古いAI結果を現在相場の結果として扱わない

### 2. トークン節約
- ダッシュボード更新ではDeepSeekを呼ばない
- AI比較はユーザーがボタンを押した時だけ
- 同一スナップショット + 同一モデル + 同一推論設定は短時間キャッシュ
- キャッシュ再利用時は今回0 tokens、節約推定tokensも表示
- AIへ渡す注目銘柄を最大8件へ縮小
- 既定最大出力を300 tokensへ縮小
- AIには数値再計算をさせず、Windows側で計算済みの圧縮データだけを送る
- 1日AIトークン上限を設定可能（既定20,000、0=無制限）
- 上限を超えそうな新規AI問い合わせは送信前に停止

### 3. システム健康状態
ホームで次を確認できます。
- Windowsブリッジ
- Excel同期（市場ファイル更新時刻から推定）
- 市場データ鮮度
- DeepSeek設定状態
- 重要指標データ状態
- 最終市場ファイル更新からのおおよその秒数

### 4. 注目銘柄のスキャルピング適性
AIを使わず、次を材料に0〜100で候補整理します。
- 騰落率
- 出来高倍率
- スプレッド
- 日中値幅（取得できる場合）

これは利益確率ではありません。あくまで「短期売買で観察しやすい条件」の整理用です。

### 5. スマホ前面時だけ5秒更新
Androidが前面にある間だけダッシュボードを5秒ごとに更新します。バックグラウンドへ移ると停止します。この更新はDeepSeekを呼ばないためAIトークンは消費しません。

## APIキー保護
- DeepSeek APIキーはAndroidへ永続保存しない
- Android → WindowsはAES-GCMで暗号化
- Windows側はDPAPIで保存
- Android側のペアリング秘密はAndroid Keystoreで保護
- 成功応答にもHMAC署名を付け、Androidで検証
- 設定画面はFLAG_SECUREでスクリーンショット/画面録画を抑止
- APIキーをログ出力しない

## Android権限
Manifestで利用するのはネットワーク接続に必要な `INTERNET` のみです。現在版では位置情報、写真、連絡先、マイク、ストレージ、カメラ、通知の実行時権限は要求しません。

## MarketSpeed II RSS / Excel
`MARKET` シートのA列から次の順です。

`code, name, price, prev_close, volume, avg_volume, bid, ask, high, low, timestamp`

K列timestampは実際の更新時刻を入れてください。**K列が空欄の場合、Excelを今読み取った時刻を株価更新時刻として偽装しません。** timestampが無い、解析できない、2分以上古いデータは古いデータとして除外します。

## 使い方
1. Windowsで `windows/setup_windows.bat` を1回実行。
2. `windows/run_windows.bat` を起動し、URLと64桁ペアリングコードを確認。
3. Android Studioで `android` を開いて端末へインストール。
4. Androidの「設定 → Windows接続」でURLとコードを入力。
5. DeepSeekを使う場合だけAPIキーを登録。
6. `AutoTradeMarket.xlsx` を開き、`windows/run_excel_sync.bat` を起動。
7. 通常はAIなし判定と注目銘柄を見る。
8. 必要な時だけ「AIと比較」を押す。
9. 設定で1日のAIトークン上限を決める。

## 意図的に入れていない機能
機能過多とトークン浪費を避けるため、現在は次を入れていません。
- 銘柄ごとの自動AI連打
- 数秒ごとのAI自動分析
- SNS/X/掲示板センチメント
- 大量のテクニカル指標表示
- 本格チャート描画
- QRペアリング（カメラ権限を増やさない）
- クラウド会員登録
- Androidバックグラウンド常駐監視
- 未検証の実注文
